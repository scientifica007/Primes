# Primes

تجربة منهجية للبحث عن الأعداد الأولية ومقارنة طريقتين لتنفيذ الفكرة نفسها.

## الفكرة الأصلية

نبدأ بقائمة الأعداد الطبيعية حتى حد أعلى `N`، ثم:

1. نحذف الأعداد الزوجية، وتسمى القائمة الناتجة **أ**.
2. نضع `2` و`3` في قائمة الأعداد الأولية.
3. نحذف مضاعفات `3` من **أ**، وتسمى القائمة الناتجة **ب**.
4. كل عدد باقٍ يحقق `3 < n < 3²` هو عدد أولي.
5. نأخذ العدد الأولي التالي `5`، ونحذف مضاعفاته من **ب** لنحصل على قائمة جديدة.
6. كل عدد باقٍ يحقق `5 < n < 5²` هو أولي، مع عدم إعادة إدراج الأعداد التي صُنفت سابقًا.
7. ننتقل إلى العدد الأولي التالي ونكرر العملية.

الأساس الرياضي هو أن العدد المركب `n` يملك عاملًا أوليًا لا يتجاوز `sqrt(n)`. لذلك، بعد حذف مضاعفات جميع الأعداد الأولية حتى `p`، لا يمكن أن يبقى عدد مركب أصغر من `p²` لم يُحذف بعامل أصغر.

> العدد `1` مستبعد صراحةً لأنه ليس أوليًا ولا مركبًا.

## الملفات

### `original_method.py`

نسخة مرجعية تحافظ قدر الإمكان على بنية التجربة الأصلية:

- تنشئ قائمة الأعداد الطبيعية.
- تنشئ قوائم المضاعفات.
- تطرح المضاعفات من قائمة المرشحين مرحلة بعد مرحلة.
- تصنف المرشحين في المجالات المحددة بواسطة مربعات الأعداد الأولية.
- تجمع إحصاءات عن عدد القيم المولدة واختبارات الحذف والتصنيف.

تشغيل مثال:

```bash
python original_method.py 100
```

### `optimized_method.py`

نسخة محسنة حسابيًا مع الحفاظ على المبدأ الرياضي:

- لا تنشئ قوائم منفصلة للأعداد الطبيعية والمضاعفات.
- تستخدم مصفوفة منطقية للمرشحين.
- تبدأ شطب مضاعفات العدد الأولي `p` من `p²`.
- بعد معالجة الأعداد الأولية حتى `sqrt(N)` تكون كل القيم غير المشطوبة أولية.

تشغيل مثال:

```bash
python optimized_method.py 100
```

## المقارنة التجريبية

الملف `benchmark.py` يقارن النسختين من حيث:

- صحة الناتج وتطابق قائمتي الأعداد الأولية.
- زمن التنفيذ.
- ذروة الذاكرة المرصودة بواسطة `tracemalloc`.
- عدد من مؤشرات العمليات الداخلية لكل خوارزمية.

تشغيل المقارنة الافتراضية:

```bash
python benchmark.py
```

تحديد مجالات أخرى:

```bash
python benchmark.py 1000 10000 100000 1000000
```

وحفظ النتائج بصيغة CSV:

```bash
python benchmark.py 1000 10000 100000 --csv results.csv
```

## اختبارات الصحة

```bash
python -m unittest -v
```

يتحقق `test_primes.py` من النتائج المعروفة حتى 100، ومن الحالات الحدية الصغيرة، ومن تطابق النسختين لكل حد من 0 إلى 500.

## هدف التجربة

الهدف ليس مجرد إنتاج قائمة الأعداد الأولية، بل دراسة التحول من صياغة مباشرة قائمة على إنشاء القوائم وطرح المضاعفات إلى صياغة أكثر كفاءة، ثم قياس أثر كل تحسين على الزمن والذاكرة وعدد العمليات، مع الحفاظ على قابلية التحقق من صحة النتائج.
